# 有槽齐平接触，demo E = 100 GPa，粒距 1 mm

**日期：** 2026-10-18
**命令：** `test_3d_spdb_geometry --slot_contact --dp 0.001 --contact_stiffness_scale 1 --end_time 0.0015`
**材料：** `LinearElasticSolid`，E = 100 GPa、ν = 0.30（demo_assumption）。
**几何：** 下体接合面减 10 mm 立方盲槽；上体无槽。接合面只接触、无摩擦。
**接触：** `ContactForce`（罚函数）。不是 `RepulsionForceCK`，也不改 `src/`。

这是弹性声学时间平衡，不是 60 s 保压，没有非弹性。空腔体积未重建、未宣称。

## 定义

- 接合面穿透：槽外圆环上 `(z_upper − z_lower) − dp < 0`。
- 空腔中心净高：槽内顶面粒子平均 z 减去槽底粒子平均 z。底板粒子在材料内侧，约为 `−slot_depth − 0.5·dp`；顶面约为 `+0.5·dp`。初始中心净高 11 mm = 10 mm 几何净空 + 1 mm 粒距。
- 顶壁挠度：槽上方顶面平均 z 减去接触圆环上体平均 z。负值表示顶壁相对接触环向下凹进空腔。
- 孔高变化不能画成蠕变。

## 结果

退出码 0，墙钟 700 s，21386 步。下体 24280 粒子，上体 25280。接触对 1164（齐平无槽是 1264）。

| 量 | 值 |
|----|----|
| 最大穿透 | 0.906 µm |
| 占粒距 | 0.0906% |
| 接触合力互消 | 1.2×10⁻¹¹ |
| 反力相对误差 | 1.5×10⁻⁹ |
| 初始空腔中心净高 | 11.000 mm |
| 终了空腔中心净高 | 10.9971 mm |
| Δ 净高（弹性） | −2.871 µm |
| 最小中心净空 | 10.9968 mm |
| 槽底跨度 x / y | 9.0005 mm |
| 顶壁挠度 | −0.601 µm |
| 下体 / 上体轴向应变 | −1.031×10⁻⁴ / −9.916×10⁻⁵ |

同一名义力下，无槽齐平穿透是 0.707 µm。有槽后接触面积更小，穿透略大到 0.906 µm，仍属亚微米。弹性 Δ 净高 2.87 µm 已大于 600 s 无孔芯部蠕变对应的约 44 nm，后续保压必须把穿透/弹性闭合与非弹性分开记。
