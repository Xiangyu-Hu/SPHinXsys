# Ren 2014 材料点核对

**日期：** 2026-10-17
**命令：** `test_3d_spdb_geometry --material_point`
**模型：** `ren2014_x20cr13`，DOI `10.1016/S1003-6326(14)63206-4`
**结果：** 退出码 0，`material_point_failures=0`。这是热压缩公式的实现核对和低速外推估算，不是孔塌陷预测。

源码在 `tests/extra_source_and_tests/extra_src/shared/spdb_arrhenius.h` 与 `spdb_arrhenius.cpp`。系数说明在 `material_20cr13_arrhenius.md`。原始表在 `results/material_point_reference.csv`，日志在 `results/material_point.log`。

## 核对

四个附录核对点的系数和 1223.15 K、0.01 s⁻¹ 流动应力，最大相对误差约 3.8×10⁻¹⁰，门槛是 1×10⁻⁶。

1173、1223、1423 K，应变 0.05、0.5、0.75，应变率 0.01、0.1、1、10 s⁻¹ 的正反向往返，最大相对误差约 5×10⁻¹⁵。Pa 与 MPa 路径一致。等效应力为 0 时速率为 0。纯静水应力的 von Mises 等效应力为 0，单轴 −10 MPa 的等效应力为 10 MPa。

## 10 MPa、7200 s

默认端点延拓，历史应变从 0 开始，系数取 ε = 0.05。速率 4.295261254×10⁻⁹ s⁻¹，低于拟合下限 0.01 s⁻¹，标记为低速外推，没有钳制到 0.01。累积应变 3.092588103×10⁻⁵。步长 60、30、15 s 与常速率参考的相对差约 2×10⁻¹²。

`poly_to_zero` 在同一载荷下的应变是 3.06895×10⁻⁵，和端点延拓同一量级。

20 mm 高度上，3.09×10⁻⁵ 应变大约是 0.62 µm。1 mm 接触算例的最大穿透是 33 µm。在把这个本构放进粒子计算之前，孔高变化会先被接触闭合盖住。

## 弹性模量

Ren 2014 没有给 E、ν、ρ。材料点里暂记 `demo_assumption`：E = 100 GPa，ν = 0.30，ρ = 7750 kg/m³。0.5 倍、1 倍、2 倍模量只改变 10 MPa 下的弹性应变（−2×10⁻⁴、−1×10⁻⁴、−5×10⁻⁵），不改变非弹性增量。这组模量不能写成论文数据，也不能代替原来的 2 GPa 合成回归。

## 小变形单轴 J2

流动仍在 Cauchy 等效应力上计算，没有把流动应力写进 PK2。单轴压缩分支是 σ_zz = E (ε_zz − ε_in,zz)，ε_in,zz = −p，p 的速率由 Arrhenius 等效应力给出。方向核对：σ_zz = −40 MPa、等效速率 0.001 s⁻¹ 时，D_zz = −0.001 s⁻¹，D_xx = D_yy = +0.0005 s⁻¹，非弹性体积率为 0。相对误差约 2×10⁻¹⁶。

隐式后向欧拉只在本步试算；超 0.75 或括号失败则不提交。加载按瞬时弹性升到目标应力，保压期才累积非弹性，因此省略了升载过程中的非弹性。

| 检查 | 结果 |
|------|------|
| 应变率 −0.01 s⁻¹，先走到 \|ε\| = 10⁻⁵ | 等效应力 1.000 MPa，与 E\|ε\| 相对差约 9×10⁻¹⁴。拟合窗流动应力约 79.6 MPa，这一步仍是弹性瞬态 |
| 同一应变率走到 \|ε\| = 0.20，Δt = 0.025 s | 非弹性应变 0.198987，等效应力 101.310 MPa。同一 p 上的流动应力 101.321 MPa，相对差 1.04×10⁻⁴ |
| Δt 从 0.05 s 收到 0.025 s | 终应力相对变化约 1×10⁻⁷ |
| E 取 0.5× / 1× / 2×，Δt = 0.05 s | 终应力 101.222 / 101.310 / 101.354 MPa。差别来自弹性应变占掉的那一小段 p，不是另写了一套流动曲线 |
| 10 MPa 持荷 7200 s 再卸载 | p = 3.092588103×10⁻⁵，与常速率参考相对差小于 10⁻⁶。卸载后应力和速率为 0，残余应变等于 −p，恢复的弹性应变为 −1×10⁻⁴ |

这仍是材料点积分，不是 7200 s 的 SPH 保压。合成弹性的接触刚度对照见 [`elastic_contact_stiffness_results.md`](elastic_contact_stiffness_results.md)。

速率函数放在 `spdb_arrhenius_ck.hpp`，用库里的 `math::`，没有输入输出，也没有 `std::string`。固定总应变下的 J2 回映是 `sigma_new = sigma_trial - 3 G rate dt`。试算 80 MPa、G 按 E = 100 GPa 和 ν = 0.3、Δt = 0.05 s，残差相对值约 7×10⁻¹⁶，应力收到 66.43 MPa。粒子上的类是 `Ren2014X20Cr13Solid`，非弹性步写在 `ConstituteKernel::ElasticLeftCauchy`，和 `HardeningPlasticSolid` 接到 `StructureIntegration1stHalf` 的位置相同。圆柱算例还没有改用这个积分器。
