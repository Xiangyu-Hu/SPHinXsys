**使用状态：** 系数已进入材料点模块 `spdb_arrhenius`。这是热压缩流动应力的文献参考，不是 950℃、10 MPa、7200 s 的已验证蠕变预测，也不是孔塌陷预测。

甲方早先只转来 `ln A(ε)` 和两套激活能。该文式 13–16 的五阶多项式已按计划附录核对，α、n、Q、ln A 不再缺项。拟合应变率下限是 **0.01 s⁻¹**，不是 0.001 s⁻¹。正文排除了 0.001 s⁻¹ 的多峰数据。413 kJ/mol 不属于这套多项式，不能拿来替换 Q。

## 1. 适用范围

试验温度 1173–1423 K，压缩真应变写到 0.8。实际拟合窗口是 1173–1423 K、0.01–10 s⁻¹、真应变 0.05–0.75，应变采样间隔 0.05。

950℃ = 1223.15 K。对照原文曲线用 1223 K。本项目演示温度用 1223.15 K，两者都在拟合温度窗内。

低于 0.01 s⁻¹ 的保压速率是外推。材料点允许这种外推并打上 `low_rate_extrapolation`，不把速率钳到 0.01。历史应变从 0 开始。默认只在计算系数时用 `ε_eval = max(ε_in, 0.05)`，这是端点延拓，不是 5% 预应变。`poly_to_zero` 把多项式直接用到 0.05 以下，只作敏感性。`ε_in > 0.75` 时停止。

## 2. 多项式

`p(ε) = c0 + c1 ε + c2 ε² + c3 ε³ + c4 ε⁴ + c5 ε⁵`。α 的单位是 MPa⁻¹。应力若用 Pa，则 `α_Pa = α_MPa / 10^6`。Q 已经是 J/mol。`ln A` 是自然对数，A 按 s⁻¹。R = 8.314 J/(mol·K)。

| 次数 | α (MPa⁻¹) | n | Q (J/mol) | ln A |
|------|-----------|---|-----------|------|
| 0 | 0.01277 | 7.19785 | 454181 | 40.18281 |
| 1 | -0.04834 | -12.73951 | -319488 | -29.51957 |
| 2 | 0.18608 | 57.97832 | -28978.6 | 2.19563 |
| 3 | -0.36932 | -145.77045 | 1777650 | 134.56396 |
| 4 | 0.37353 | 168.05383 | -3257280 | -247.06753 |
| 5 | -0.15155 | -71.91728 | 1745480 | 130.34468 |

正向：

```text
ε_dot = exp(ln A − Q/(R T)) * sinh(α σ)^n
```

反向：

```text
σ = asinh( exp( (ln ε_dot + Q/(R T) − ln A) / n ) ) / α
```

σ 用非负等效应力。压应力的负号不进入 sinh。

ε = 0.5 时多项式给出的常数，和文中该应变单独辨识的 α=0.00757 MPa⁻¹、n=5.366、Q=359402 J/mol、ln A=31.341 略有差别。实现只用整套多项式。

## 4. 本文没有给出的量

E(T)、泊松比、热膨胀、密度、导热、比热、电阻率和界面摩擦都不是这篇论文的结果。等温材料点不需要它们。三维演示若用弹性模量，必须另标 `demo_assumption`，不能写成 Ren 2014，也不能继续把合成 2 GPa 叫做这套钢的模量。

打印成分里 Cr 写作 0.131（质量百分比）与牌号常识不符，不自动改写成 13.1%。热历史文字和部分试验温度也不一致。这不影响使用上面的本构系数。
