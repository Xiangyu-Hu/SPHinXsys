# OPHELIE 电磁感应焊接能力展示：Cursor 分阶段实施计划

**项目性质：** 演示级（demonstration），非验证级（validated engineering prediction）  
**建议优先级：** Case A 必做；Case B 在 A 稳定后扩展  
**技术路线：** 复用 SPHinXsys 现有 OPHELIE `Biot–Savart` 线圈源场 + 电势 `φ` + `E/J/Joule` 后处理，不切换到 Laplace 型 A–φ 求解器  
**核心原则：** 不重构求解器，不修改电磁核心数学公式以迎合结果，不将未经验证的云图宣传为焊接工艺预测。  
**进度（2026-10-10）：** Gate 0–4 **PASS**。Case A VTP：`case_a_vtp/`；Case B VTP：`case_b_vtp/`（含线圈 `z=0` / `z=0.025` 对比）。演示级，非焊缝预测。

## 2. Case A：线圈感应加热金属圆柱（优先完成）

### 2.1 目的

最小化几何和边界复杂度，快速复用已有 Biot–Savart + `φ` + Joule 流程，产出最直观的 3D 演示。

### 2.2 建议初始几何（SI 单位）

以 **z 轴**为线圈与工件共同轴线（如果现有 OPHELIE 实现硬编码 y 轴，优先通过几何参数一致地沿 y 轴布置，**不要**在部分模块中混用坐标轴）：

| 参数 | 初始值 | 备注 |
|---|---:|---|
| 工件材料 | 非磁性铝，常数物性 | 简化；`μ_r = 1` |
| 工件半径 `R_work` | `0.020 m` | 实心圆柱 |
| 工件长度 `L_work` | `0.100 m` | 中心置于原点 |
| 线圈平均半径 `R_coil` | `0.035 m` | 与工件留 15 mm 径向间隙 |
| 线圈匝数 `N` | `5` | 5 个独立闭合圆环，或现有离散线圈表示 |
| 匝间距 `pitch` | `0.012 m` | 中心对称排列 |
| 激励频率 `f` | `10 kHz` | 首轮示意参数，不代表研究所工艺 |
| 电流幅值 `I_peak` | `500 A` | 明确是峰值，不是 RMS |
| 电导率 `σ` | `3.5e7 S/m` | 铝的示意常数，温度效应忽略 |
| 磁导率 | `μ0` | 非磁性近似 |
| 初始粒子间距 `dp` | `0.004 m` | 仅供粗网格冒烟测试；不适于解析细薄趋肤层 |

注：以上参数用于演示几何和工作流，不作为准确感应加热设计。`f=10 kHz` 下铝的趋肤深度约为 0.85 mm，远小于 `dp=4 mm`；因此粗网格**不能**宣称定量解析了趋肤效应或精确热源峰值。若想展示真实表面局部化，需要局部加密或降低频率并验证收敛。可先以较低频率做数值可行性检查，再逐步上调。

### 2.3 需要输出的物理量

- 线圈几何与工件几何；
- `B_src_x`, `B_src_y`, `B_src_z`, `B_src_mag`；
- `phi_real`, `phi_imag`（如果已有复数场输出）；
- `E_mag`, `J_mag`, `JouleHeat`（仅在电势求解正常时）；
- `P_joule = Σ_i q_{J,i} V_i`；
- `phi_residual`, `divJ` 相关诊断（用已有实现，不要自造不一致定义）；
- 轴线磁场曲线和径向 `|J|`/`q_J` 剖面（如果可用）。

### 2.4 可视化布局

**图 A1：** 半透明金属圆柱 + 5 匝线圈 + `|B_src|` 切片；  
**图 A2：** 圆柱表面或纵剖面 `|J|`；  
**图 A3：** `q_J` 纵剖面；  
**图 A4：** 线圈电流与总热功率的参数表。  

所有色标必须标单位；如进行逐图自动归一化，注明“normalized for visualization”，不能据此比较不同参数的绝对强度。

## 3. Case B：两段金属管连接处局部感应加热

### 3.1 目的

展示与焊接更接近的局部感应热源集中效应。**此 Case 只模拟焊接前的电磁感应加热，不模拟熔化、接合或焊缝质量。**

### 3.2 几何建议

使用两段同轴铝管（仍为非磁性），线圈布置在轴向接头附近。为避免几何导致求解器复杂度激增，第一版优先采用**两段在几何上接触、计算上视为单个连续导电域的管件**，接缝用标记面显示，而不立即求解接触电阻。如果要显式保留绝缘间隙，则需保证导电域分离和 `φ` 的连通分量处理正确。

| 参数 | 初始值 |
|---|---:|
| 管外半径 | `0.025 m` |
| 管内半径 | `0.015 m` |
| 总长度 | `0.120 m` |
| 名义接缝位置 | `z = 0` |
| 线圈平均半径 | `0.040 m` |
| 线圈匝数 | `3` |
| 匝间距 | `0.010 m` |
| 线圈中心位置 | `z = 0`（对准接缝） |
| 频率、电流 | 首轮沿用 Case A；根据运行表现调整 |
| 材料 | 与 Case A 一致 |

第一版将接缝视为**几何位置标记**，并非真实接触/焊缝界面；如果研究所特别关注搭接焊或异种金属，等拿到真实工艺信息后再替换几何。

### 3.3 建议输出

- 线圈与两段管件三维展示，接缝位置标记；
- `|B_src|`、`|J|`、`q_J` 轴向截面；
- 沿轴线 `z` 的分段积分功率密度 `P'(z)`；
- 接缝邻域吸收功率占比：

  `eta_joint = (Σ_{|z_i|<L_joint/2} q_{J,i} V_i)/(Σ_all q_{J,i} V_i)`，建议 `L_joint = 0.020 m`。

- 可选对比：线圈中心在 `z=0` 和 `z=0.025 m` 两个位置的结果。**比较时使用相同单位和固定色标范围**。

## 4. 物理模型与实现边界

使用当前 OPHELIE 的**源场近似**：

`A_src, B_src ← Biot–Savart(coil)`  
`E_hat = -jω A_src - ∇phi_hat`  
`J_hat = σ E_hat`  
`q_J = 0.5 Re(J_hat · conj(E_hat))` （**峰值相量约定**）

`phi` 通过 `∇·J_hat=0` 约束求解。请 Cursor 检查当前代码实际采用的相量正负号、源项定义、单位、`ω=2πf`、以及是否使用峰值还是 RMS 约定；必须沿用同一套约定，不允许混用。

**重要限制：** 若 OPHELIE 当前只计算外加线圈源场，不计算感应电流的二次磁场，则在高导电率/强趋肤效应工况下可能出现明显物理误差。演示可以采用此近似，但必须在 README 和展示页标注；不能通过更改色标掩盖非物理数值。

### Gate 3：φ、感应电流、焦耳热

1. 使用现有 `φ` 求解流程，不同时修改离散算子、预条件器和几何。

3. 输出复数 `φ`、`E`、`J`，计算 `q_J`；确认 `q_J≥-tol`（容忍舍入误差），所有结果有限。
4. 记录求解器退出状态、迭代次数、相对残差、电流散度诊断、功率积分。
5. 检查线圈电流从 `I` 改为 `2I` 时，在固定物性、线性系统和相同收敛条件下 `|J|` 应近似翻倍、`P_J` 应近似变为四倍。若不满足，先定位问题，不用归一化图片掩盖。
6. 若 `φ` 求解未收敛，**不能把非收敛 J/Joule 结果当作已验证能力**；可另存为内部调试图，不进入正式演示。

## 6. 出现问题时的降级策略

| 问题 | 处理方式 |
|---|---|
| 原 OPHELIE 编译失败 | 先修构建/依赖并记录，不同步大规模改算法 |
| 线圈源场异常 | 优先核对坐标轴、匝数、线圈离散与单位 |
| `φ` 不收敛 | 保留 Case A 的 `B_src` 演示，J/Joule 暂不对外 |
| `divJ` 诊断异常 | 核对诊断与求解残差是否使用同一 edge flux；不要直接调小阈值蒙混过关 |
| 工件表面 `q_J` 极端噪声 | 先检查分辨率/趋肤深度与导电域几何，不用平滑结果替代原始场 |
| Case B 分离导体处理失败 | 回退为连续导电管 + 名义接缝标记 |
| 计算时间过长 | 先降低粒子数完成工作流演示，明确注明粗分辨率 |
| 无热传导耦合 | 只展示 `q_J`，不把热源云图命名为“温度场” |
