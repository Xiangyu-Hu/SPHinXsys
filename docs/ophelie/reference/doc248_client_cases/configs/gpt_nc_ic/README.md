# 甲方自然对流工况的初始温度场

这是轴对称非均匀热启动场，可用于 248 任务 C0 的玻璃粒子初始化。随后由设置中的热边界、体积热源和自然对流自由推进。扰动、稳态与搅拌后温升需要相应时程另行判断。

## 依据和假设

| 项目 | 本版值 | 依据 |
|---|---:|---|
| 中心轴，液面下 20 mm | 817.54 °C / 1090.69 K | 248 任务书记录的甲方既有测温 |
| 中心轴，液面下 70 mm | 1068.82 °C / 1341.97 K | 同上 |
| 中心轴，液面下 120 mm | 980.66 °C / 1253.81 K | 同上 |
| 玻璃半径与液深 | 141.5 mm，230 mm | 内径沿用开发几何；液深按甲方要求 |
| 液面中心、底面 | 790 °C、810 °C | 工程假设 |
| 表面热环 | 峰值约 1246 °C，半径约 108 mm | 照片约束相对位置，温度为假设 |
| 内部高温区 | 峰值约 1474 °C，半径约 91 mm、液面下约 44 mm | 按草图构造；热区随深度向轴线方向倾斜 |
| r/R = 0.5、液面下 120 mm | 约 1003 °C | 模型独立读数。轴线三点之外，无桨约 1000 °C 仅作量级交叉检查 |

照片给出可见表面暗中心和亮环带。曝光、发射率、反射及可能存在的表层变化都会影响亮度。表面中心 790 °C、壁侧温度、底部温度及内部峰值均为初值假设。轴线点与照片是否同一时刻尚未核实。轴对称近似平滑掉了方位角方向的亮斑。1400 °C 是另一次描述中的搅拌阶段测点温度，本场未将其作为约束。模型中高于 1400 °C 的体积约占 3.6%，只用来量化本假设场的初始热储区。初始温度落在 1050–1800 K 物性使用区间内。靠壁温度指玻璃液侧初值。

## 赋值方法

建议直接调用 `client_nc_initial_temperature.h` 中的 `ophelie_client_nc::temperature_K`。半径、深度及域尺寸使用 m，返回 K。现有代码快照中的求解器通常为 +Z 向上。在该坐标系中使用：

```cpp
const double radius_m = std::hypot(x - x_axis, y - y_axis);
const double depth_m = z_surface - z;
const double initial_temperature_K =
    ophelie_client_nc::temperature_K(radius_m, depth_m, melt_radius_m, melt_height_m);
```

若实际求解器以 +Y 向上，径向距离改用 x–z 平面，深度为 y_surface−y。轴心和液面来自该次运行的有效玻璃域。开发几何快照中液底 z = 0.001 m，H = 0.230 m 时液面 z = 0.231 m。优先以实际计算粒子与有效配置确认这些坐标。

在初始粒子加载后、温度依赖物性和首轮热源求解前，对玻璃域赋值一次。若求解字段存温升，则写入 `initial_temperature_K - T_reference_K`，并使初始化后的绝对温度与物性更新一致。检查点续算应读取保存状态。测点保持被动采样，初值场不重复覆盖。水冷、顶面散热、热源和其他物体的初值由各自设置控制。热启动后先检查温场和热量账本，再接续搅拌算例。

液深按甲方要求改为 230 mm。液面下 0–150 mm 沿用原温度剖面，三个测点保持各自的物理深度。150–230 mm 区间对原下部剖面做平滑延展，底面仍取 810 °C，连接处温度和竖向梯度连续。初始化时以实际液面定位测点。旧粒子几何若仅覆盖 180 mm，需要按 230 mm 液深重新准备玻璃粒子或使用匹配的粒子数据。

## 数据和构造

- `initial_temperature_r_depth.csv` 为约 1 mm 间距的半剖面采样，包含精确壁点 r = 141.5 mm，提供 °C 和 K 两列。可按 (r, d) 双线性插值。CSV 列中的深度从液面向下为正。
- `initial_temperature_parameters.json` 包含轴线测点、下部深度映射、底层插值节点、环带和壁侧参数及峰值诊断。轴线使用保形三次 Hermite 插值通过三个测点，表面和底面各有一个假设端点。
- 径向函数以 s = (r/R)² 构造，等于轴线温度加环带项和壁侧回落项。环带项在轴和壁都为零，环带幅值随深度衰减，热环形状参数随深度平滑向内移动。外侧逐渐接近旁壁玻璃液的假设温度，底面为 810 °C。该写法使轴线的径向一阶导数为零。
- 实测点用于构造初值。与这些点相符是初始化检查，计算后时程才用于判断物理解是否维持合理温度分布。
